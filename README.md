# To-Do List Life Dashboard

Dashboard sederhana untuk mengatur fokus dan aktivitas harian.

## Fitur

- Salam sesuai waktu, jam, dan tanggal terkini
- Focus Timer 25 menit: mulai, berhenti, reset
- To-do list: tambah, edit, selesai, hapus
- Local Storage untuk tugas, nama, tema, dan quick links
- Quick links yang dapat ditambah dan dihapus
- Light/Dark mode, nama kustom, dan pencegahan tugas duplikat

## Menjalankan proyek

Buka `index.html` menggunakan browser modern.

Tidak membutuhkan backend atau instalasi package.
